# Music Downloader

Sistema para baixar músicas a partir de links do Spotify, com lógica inspirada no
[spotDL](https://github.com/spotdl/spotify-downloader).

- `web/` — Angular + TailwindCSS
- `functions/` — Cloud Functions (TypeScript)
- Firebase: projeto compartilhado `javitech-8797d`, com recursos exclusivos deste sistema
